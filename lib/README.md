# lib

插件的两个出口。**功能全部住在 `client.js`**，这里没有构建步骤，也没有运行期依赖。

| 文件 | 作用 |
| --- | --- |
| `client.js`（≈7.4k 行） | 浏览器半：选区读取、线格式、芯片插入、发送后胶囊、坐标与跳回、高亮、草稿聚合条、侧边对话、引用清单页、快捷键、`apply` 装配。顺序见文件顶部注释与 [`../AGENTS.md`](../AGENTS.md) 的路由表。 |
| `index.js` | host 半：只有一个空 `apply()`，用来标记 loader 入口已组合。不要在这里加服务、路由或逻辑。 |

## 改这里之前

- bundle 内只 `require("react")`；不加 lodash / 日期库 / ESM `import`，`test/check.mjs` 会拒绝未知 require。
- 不拆新模块、不引 TS 或打包器；所有功能继续留在 `client.js`。
- 不搬移、不改写宿主 React 节点；胶囊是「隐藏原 run + 在前插入自己的节点」，且可还原。
- 线格式只增不改，旧消息必须继续可读；坐标随消息文本走，本机索引只是缓存。
- 宿主服务缺失时静默降级，绝不让整个插件挂掉。

完整红线（R1–R22）见 [`../AGENTS.md`](../AGENTS.md)；产品行为口径见 [`../README.md`](../README.md) 的功能表。
