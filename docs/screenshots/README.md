# docs/screenshots

根 README「界面」一节使用的界面素材，全部是静态截图 / 静态合成，不是实时录屏。

| 文件 | 内容 |
| --- | --- |
| `bar.png` | 选中文字后浮出的「评论 / 添加到对话 / 侧边对话」浮层，位置贴着选区。 |
| `comment.png` | 评论框：引用正文与评论各占一个输入框、都可编辑，可勾选「让模型逐条回应」。 |
| `card.png` | 发送后的胶囊与悬停卡片：引用、评论、跳回原文、改这条引用、复制。 |
| `panel.png` | 右侧栏「引用清单」页：搜索、跳回、导出与侧边线程回流。 |
| `overview.gif` | 四张截图合成的 24 秒轮播，顺序为浮层 → 评论 → 胶囊卡片 → 引用清单。 |

## 替换约定

- `test/check.mjs` 会遍历本目录，要求每个文件名都出现在根 [`README.md`](../../README.md) 里（`docs/screenshots/<name>`），所以新增或删除素材必须同步改根 README。
- 200% / 高分屏截图请先缩放再放入，避免 README 首屏过大。
- 本目录没有构建脚本；素材是手工截取、合成后提交的。
